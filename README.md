# Supply-Chain-Operations

Developed a two-page interactive Excel dashboard for Apex Logistics to analyze supply chain operations using Pivot Tables, Pivot Charts, Slicers, Timeline, and Excel formulas.

The dashboard tracks 1,084 orders with ₹90.43M revenue and ₹22.26M profit while monitoring warehouse performance, supplier efficiency, delivery timelines, inventory levels, shipping costs, and product profitability.

Key insights include monthly order trends, revenue by product category and state, order status distribution, transport mode usage, supplier performance, top profitable products, shipping cost analysis, and inventory vs reorder level.

This project helps businesses improve operational visibility, optimize inventory planning, evaluate supplier performance, and support data-driven logistics decisions
